# Bundled fonts

All families ship unmodified static binaries from their official upstream
sources, with each family's license and copyright/Reserved Font Name notices
preserved (see `licenses/`). None of the files are subsetted.

| Family | Weights | License | Copyright / Source |
| --- | --- | --- | --- |

| Space Grotesk | Regular, Bold | OFL 1.1 | © Florian Karsten — https://github.com/floriankarsten/space-grotesk |
| Fraunces | Regular, Bold | OFL 1.1 | © The Fraunces Project Authors — https://github.com/undercasetype/Fraunces (144pt optical cut; file names normalized, name tables untouched) |
| Playfair Display | Regular, Bold | OFL 1.1 | © Claus Eggers Sørensen — Playfair Display v1 (upstream evolved into "Playfair") |

them in the heading font selection only.
